# feb-day 💖

A dark romantic interactive webpage to ask someone to be your Valentine!  

Inspired by [SahilGogna/v-day](https://github.com/SahilGogna/v-day), this version adds new features, animations, and a cinematic celebration for when they say "Yes".

---

## Features

- 💌 **Name Input**: Personalize the experience by entering your Valentine’s name.
- 💔 **Playful “No” Responses**: If the Valentine says "No", the site will respond with playful messages and make the No button move randomly.
- ❤️ **Expanding Yes Button**: The Yes button grows slightly every time the Valentine says No.
- 💥 **Celebration Page**: When the Valentine says Yes:
  - Big heart explosion
  - Floating hearts
  - Confetti and fireworks
  - Background particle glow
  - Rotating romantic quotes
  - Autoplay romantic music
- 🌙 **Dark Romantic Theme**: Elegant dark colors with soft red glows.
- 📱 **Mobile Friendly**: Fully responsive and interactive on mobile devices.
